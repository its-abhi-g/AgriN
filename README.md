# AgriN

**Agricultural Intelligence Network**

AgriN is an AI-powered agricultural decision-support prototype
designed primarily for Indian farmers.

## Problem

Farmers often have access to large amounts of agricultural
information, but converting that information into timely,
practical decisions can be difficult.

## Solution

AgriN allows farmers to describe an agricultural problem
naturally and uses Google Gemini to convert the problem into
structured agricultural guidance.

## Core Workflow

Farmer Input

↓

Gemini Understanding

↓

Farm Context

↓

Risk Analysis

↓

Action Plan

↓

Farmer-Friendly Guidance

## Features

- Natural-language farmer queries
- English and Hindi support
- Optional farm context
- Gemini agricultural analysis
- Structured recommendations
- Agricultural risk levels
- Responsible-AI safeguards
- Demo scenarios
- Farm Insights demo dashboard
- Mobile-friendly Streamlit interface

## Technologies

- Python
- Streamlit
- Google Gemini
- Google GenAI SDK
- Pydantic
